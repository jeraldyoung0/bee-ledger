# 蜜蜂记账（BeeLedger）

一个**完全本地**的安卓记账 App：你在微信、支付宝、银行 App 里付完钱，它会自己记一笔，并且自动分好类。

> 本项目是为「编程几乎零基础」的你准备的：代码已经写好，你只需要照着做一次「上传 → 等 3 分钟 → 下载 APK → 安装」。
> 全程不需要安装 Android Studio（约 10GB），不需要配置环境变量。

---

## 一、先说最重要的一件事：它到底能"抓"到什么

**没有任何 App 能直接读取别的 App 的数据库。** 微信、支付宝的账单存在它们自己的沙盒里，安卓系统不允许第三方读取，这是系统安全设计，不是技术不够。

所以真正能落地、并且市面上"自动记账"App 都在用的，是下面三条通道，本项目三条都做了：

| 通道 | 原理 | 覆盖什么 | 局限 |
|---|---|---|---|
| **① 通知监听** | 系统把每一条通知广播给我们，微信/支付宝/银行付款成功都会有通知 | 微信支付、支付宝、云闪付、银行 App 的消费 | 用户必须手动授予「通知使用权」；通知里没金额就抓不到 |
| **② 短信读取** | 银行交易短信 | 银行卡、信用卡、快捷支付的扣款与入账 | 需要短信权限；银行短信模板千差万别，靠规则匹配 |
| **③ 账单导入** | 支付宝/微信可以导出 CSV 账单，我们解析它 | 历史账单、通知漏掉的账 | 需要手动导出一次 |

**结论：日常消费的 80%~90% 可以被自动记上**，剩下漏掉的，可以用「手动记一笔」或「导入账单」补齐。这是目前安卓上能做到的上限，鲨鱼记账等 App 的"自动记账"也是同样原理。

详细说明见 [docs/01-可行性说明.md](docs/01-可行性说明.md)。

## 二、三步拿到 APK

### 第 1 步：把代码传到 GitHub

1. 打开 <https://github.com> 注册并登录（免费）。
2. 右上角 `+` → `New repository`，名字随便填（例如 `bee-ledger`），选 **Private** 也可以，点 `Create repository`。
3. 在新仓库页面点 `uploading an existing file`。
4. 把你电脑上 `D:\DS\APP开发` 里的**所有东西**（`app` 文件夹、`build.gradle.kts`、`settings.gradle.kts`、`gradle.properties`、`.gitignore`、`README.md`、`docs`、`build.gradle.kts`）拖进浏览器上传框，点 `Commit changes`。
   - `build` 目录如果存在，不要上传（会被自动忽略）。
   - 浏览器看不到 `.github` 这种点开头的文件夹是正常的，下一步单独建。
5. 回到仓库首页 → `Add file` → `Create new file` → 文件名输入：

   ```
   .github/workflows/build.yml
   ```

   （输入斜杠会自动变成文件夹），然后把本仓库 [.github/workflows/build.yml](.github/workflows/build.yml) 的内容整段复制进去，点 `Commit changes`。

### 第 2 步：等它自动编译

- 点仓库顶部的 **Actions** 标签，会看到一个叫 `Build APK` 的任务正在跑（黄色小圆点）。
- 大约 **2~4 分钟**，变成绿色对勾就成功了。
- 点进去，页面底部 **Artifacts** 区域有 `BeeLedger-apk`，点它下载，得到一个 zip。

### 第 3 步：装到手机

1. 解压 zip，里面是 `app-debug.apk`。
2. 把这个 apk 传到手机（微信文件传输助手、USB、网盘都行）。
3. 手机上点开安装，系统会提示"未知来源应用"，允许即可（小米/华为会多弹一两次确认）。

> 如果 Actions 里出现红色叉号：点进去看日志，把红色报错那几行发给我，我来改。
> 编译失败不需要你懂代码，这是正常的开发流程。

## 三、装好之后必须做的两件事

打开 App → 底部「我的」：

1. **通知使用权** —— 点「去开启」，在系统列表里找到「蜜蜂记账」并打开。这是自动记账的核心权限，不开就什么都抓不到。
2. **短信读取权限** —— 点「去授权」，允许即可（不开也能用，只是银行卡消费会漏）。

然后去微信给朋友转 0.01 元，或者支付宝买瓶水，回到 App 看「明细」里有没有自动出现一笔。

各品牌手机的权限路径、后台保活设置，见 [docs/03-手机授权与使用.md](docs/03-手机授权与使用.md)。

## 四、它现在有哪些功能

- **自动记账**：通知 + 短信双通道，自动生成账目，带重复过滤（同金额 3 分钟内只记一次）
- **自动分类**：内置 200+ 商户关键词（美团外卖→餐饮、滴滴→交通、星巴克→餐饮…），并会**学习**：你改一次分类，它就记住这个商户
- **明细**：按天分组，月度支出/收入/结余，点击可编辑、删除
- **统计**：分类排行（带笔数）、每日趋势柱状图、日均支出
- **预算**：设置月预算，首页显示进度条
- **账单导入**：支付宝/微信导出的 CSV，自动识别 GBK/UTF-8 编码
- **账单导出**：导出 CSV，Excel 直接打开
- **捕获日志**：抓到了什么、为什么没抓到，一目了然
- **数据完全本地**：SQLite，不联网，不上传

还没做的（可以后续加）：多账本、周期记账、记账提醒、图表分享、云同步、语音记账。

```

├─ app/
│  └─ src/main/
│     ├─ AndroidManifest.xml        权限、服务、接收器声明
│     ├─ java/com/beeledger/app/
│     │  ├─ BeeApp.kt               应用入口，初始化数据库
│     │  ├─ Core.kt                 金额/日期工具、偏好设置、刷新事件
│     │  ├─ data/
│     │  │  ├─ Model.kt             账目、规则、日志的数据结构
│     │  │  ├─ Cats.kt              分类定义（图标、颜色）
│     │  │  ├─ Repo.kt              SQLite 读写
│     │  │  └─ AutoCat.kt           ★ 自动分类词库与匹配引擎
│     │  ├─ capture/
│     │  │  ├─ Parser.kt            ★ 支付文本解析（金额、商户、收支）
│     │  │  ├─ Captors.kt           ★ 通知监听服务 + 短信接收器
│     │  │  └─ Importer.kt          支付宝/微信 CSV 导入导出
│     │  └─ ui/                     Compose 界面（明细/记一笔/统计/我的/日志/规则）
│     └─ res/                       图标、主题
├─ .github/workflows/build.yml      GitHub 自动编译配置
└─ docs/                            中文说明文档
```

带 ★ 的三个文件是"自动记账"的核心，想调整抓取和分类，改它们。

## 六、为什么没有直接改 GitHub 上的开源项目

我在 GitHub 上找过现成的：

- **BeeCount**（Flutter，2.7k stars，中文记账）：跨平台、本地优先，但它是 Flutter 工程，自动记账部分要写原生代码，对新手改造成本反而更高。
- **MyExpenses**（Java，成熟的老牌记账 App）：功能全，但采用 **GPLv3** 协议——你一旦基于它发布，就必须把自己的代码也开源，商用受限。

所以这份代码是**为你的需求新写的**，只依赖 Google 官方库，没有 GPL 传染问题，代码量控制在 4000 行以内，你能看懂主流程。想换 UI、加功能都自由。

## 七、给零基础的三句话

1. 你现在不需要"学会编程"，只需要会**改文案**和**重跑编译**。
2. 改代码只需要记事本 / VS Code，改完在 GitHub 网页上重新上传，Actions 会自动重新编译。
3. 每次改完出问题都不怕：Actions 的红色报错日志会告诉你哪一行错了，复制给我即可。
