# 02 · 编译与安装（三条路线，选一条）

> 你现在这台电脑**命令行连不上外网**（没有代理），也没有 JDK / Android SDK / Gradle，
> 所以我没法在这里直接编译。下面的路线 A 不需要你装任何开发工具。

---

## 路线 A（推荐）：GitHub 云端编译

**适合**：不想装 10GB 开发环境的人。**耗时**：首次约 10 分钟。

### A1. 注册并建仓库

1. 浏览器打开 <https://github.com>，注册 / 登录。
2. 右上角 `+` → **New repository**。
3. `Repository name` 填 `bee-ledger`（随便取）。
4. 可见性：**Private**（私有，别人看不到你的代码）或 Public 都行。
   - 私有仓库的 Actions 每月有 2000 分钟免费额度，编译这个项目一次约 3 分钟，够用几百次。
5. 点 **Create repository**。

### A2. 上传代码

在新建的仓库页面：

1. 点 **uploading an existing file** 链接。
2. 打开 Windows 资源管理器，进入 `D:\DS\APP开发`。
3. 全选这些项目，拖进浏览器上传区：
   - `app`（整个文件夹）
   - `build.gradle.kts`
   - `settings.gradle.kts`
   - `gradle.properties`
   - `.gitignore`
   - `README.md`
   - `docs`（整个文件夹）
4. 等进度条走完（约 30 个文件，很快），点绿色 **Commit changes**。

> ⚠️ 注意事项
> - 浏览器默认看不到 `.github` 这种点开头的文件夹，**这是下一步单独建的，不用管**。
> - 如果 `app` 里混进了 `build` 文件夹（里面是编译产物，很大），不要传，`.gitignore` 也会挡住它。
> - 单文件上限 100MB，本项目最大文件几 KB。

### A3. 创建自动编译配置

1. 回到仓库首页，点 **Add file** → **Create new file**。
2. 文件名框里输入（斜杠会自动建目录）：

   ```
   .github/workflows/build.yml
   ```

3. 把本地 `D:\DS\APP开发\.github\workflows\build.yml` 的全部内容复制粘贴到编辑区。
4. 点 **Commit changes**。

### A4. 等编译

1. 点仓库顶部 **Actions**。
2. 会看到名为 **Build APK** 的工作流在跑（黄点转圈）。
3. 约 2~4 分钟后变绿勾 = 成功。
4. 点进这次运行，页面**最下方** `Artifacts` 里有 **BeeLedger-apk**，点击下载 zip。

### A5. 安装

1. 解压得到 `app-debug.apk`。
2. 传到手机：微信「文件传输助手」最方便，或用数据线拷到手机存储。
3. 手机上点击 apk：
   - 系统提示"禁止安装未知来源应用" → 点"设置" → 允许该来源
   - 小米/红米会弹"风险提示"，选"仍要继续"
   - 华为会要求"纯净模式"下授权，按提示操作
4. 安装完成后桌面出现「蜜蜂记账」。

### A6. 编译失败了怎么办

红叉不要慌，这是正常现象。点进失败的那次运行 → 点红色步骤名 → 展开日志 → 找到第一处 `e: ` 开头的行（Kotlin 编译错误长这样）：

```
e: file:///home/runner/work/.../Add.kt:120:25 Unresolved reference: xxx
```

把这几行复制给我，我改代码，你重新上传那个文件即可（GitHub 网页可以直接编辑文件）。

## 路线 B：Android Studio 本地编译

**适合**：以后想长期改代码、想接手机调试。

1. 官网下载 Android Studio（约 1GB，安装后还要下载 SDK，共约 10GB）：<https://developer.android.com/studio>
2. 安装时一路 Next，勾选 Android SDK、Android SDK Platform 34、Build-Tools 34。
3. 打开 Android Studio → `Open` → 选择 `D:\DS\APP开发` 文件夹。
4. 首次打开会提示下载 Gradle 和依赖（约 5~10 分钟，需要能访问 `google.com`、`maven.apache.org`）。
5. 菜单 `Build` → `Build Bundle(s) / APK(s)` → `Build APK(s)`。
6. 完成后右下角弹窗点 `locate`，APK 在 `app\build\outputs\apk\debug\app-debug.apk`。

**注意**：`/local.properties` 会自动生成，里面是本机 SDK 路径，不要上传到 GitHub。

**没有 gradle wrapper 怎么跑？** 本项目故意不带 `gradlew`（那是个二进制文件）。在 Android Studio 里：
- 打开 `Settings` → `Build, Execution, Deployment` → `Build Tools` → `Gradle`
- `Use Gradle from` 选 `Specified location`，或让它自动下载
- 也可以在装好 Gradle 8.7 后，项目根目录执行 `gradle wrapper` 生成

如果你卡在这一步，直接走路线 A，别折腾。

## 路线 C：在你这台电脑上编译（需要先解决联网）

你这台电脑的系统代理设置里有一个 `127.0.0.1:10808`，但**当前没有程序在监听这个端口**，所以命令行上不了网。

如果哪天你打开了代理软件（Clash / v2rayN 等），告诉我，我可以：

1. 下载便携版 JDK 17（约 180MB）
2. 下载 Android 命令行工具 + SDK（约 300MB）
3. 用 Gradle 8.7 直接编译
4. 把 `app-debug.apk` 直接生成到这个文件夹里

那样你连 GitHub 都不用注册。

## 关于签名和更新

- 本项目的 APK 用的是 **debug 签名**，能正常安装使用，但**不能上架应用商店**。
- 同一个 debug 签名的新版本可以直接覆盖安装，数据不丢。
- 如果以后要长期使用 / 上架，需要生成正式签名（keystore），届时我可以教你，5 分钟的事。
- **重要**：换签名后不能覆盖安装，必须先卸载（数据会丢），所以正式签名要尽早确定。

## 常见编译问题

| 现象 | 原因 | 解决 |
|---|---|---|
| `SDK location not found` | 本地没有 SDK 或没配 `local.properties` | 走路线 A，或让 Studio 自动下载 SDK |
| `Could not resolve androidx...` | 网络访问不了 Google Maven | 需要代理；或在 `settings.gradle.kts` 里换阿里云镜像 |
| `Unsupported class file major version` | JDK 版本不对 | 必须 JDK 17 |
| `Minimum supported Gradle version is 8.7` | Gradle 太旧 | 用 8.7 或更高 |
| Actions 报 `if-no-files-found` | 编译失败，没产出 apk | 看前面步骤的红色日志 |

## 换国内镜像（如果你在国内且 Actions 用不了）

GitHub Actions 在国内偶尔慢。若只是本机编译慢，可把 `settings.gradle.kts` 里的仓库换成阿里云：

```kotlin
maven { url = uri("https://maven.aliyun.com/repository/google") }
maven { url = uri("https://maven.aliyun.com/repository/public") }
maven { url = uri("https://maven.aliyun.com/repository/gradle-plugin") }
```

放在 `google()` / `mavenCentral()` **前面**。
