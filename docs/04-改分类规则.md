# 04 · 怎么改分类规则

有三种改法，**从简单到硬核**。90% 的情况用第一种就够了。

---

## 方法一：在 App 里改（推荐）

### 1. 让 App 自己学（最省事）

1. 「明细」里点开一笔自动记的账
2. 把分类改成正确的（比如「其他」→「餐饮」）
3. 保存

如果这笔是自动记账的、且有商户名，App 会自动写下规则：

```
星巴克 → 餐饮（支出）
```

下次通知里出现「星巴克」就直接分到餐饮。**改一次，学一次。**

### 2. 手动加规则

「我的」→「分类规则」→「添加规则」：

- 关键词：`瑞幸`
- 类型：支出
- 分类：餐饮
- 保存

规则优先于内置词库，可以覆盖任何默认行为。

### 3. 删规则

「分类规则」列表里每条右边有「删除」。

## 方法二：改内置词库（改代码）

文件：`app/src/main/java/com/beeledger/app/data/AutoCat.kt`

找到 `builtin` 这个列表，格式是：

```kotlin
K("关键词", "分类名", 类型)
```

- 类型：`E` = 支出，`I` = 收入（文件里已定义）
- 分类名必须是 `Cats.kt` 里存在的名字

**示例**：让「瑞幸咖啡」和「Manner」都记成餐饮

```kotlin
K("瑞幸", "餐饮", E), K("库迪", "餐饮", E),
K("manner", "餐饮", E),          // 新增
K("瑞幸咖啡", "餐饮", E),         // 新增，更长的优先匹配
```

**示例**：新增一个「装修」关键词到居住

```kotlin
K("装修", "居住", E),
K("全屋定制", "居住", E),         // 新增
```

### 匹配规则（重要）

1. 用户规则 > 内置词库
2. 同一层里，**关键词越长越优先**
   - 所以「手机充值」会先于「手机」命中，不会被误判成数码
3. 匹配的是「商户名 + 备注 + 原始通知文本」拼起来的整串文字，不区分大小写

> 改了词库，需要重新编译（GitHub 上重新上传这个文件，Actions 会自动重编）。

## 方法三：改解析规则（最硬核）

文件：`app/src/main/java/com/beeledger/app/capture/Parser.kt`

它负责从通知/短信里抠出**金额、商户、收支方向**。

### 关键片段

```kotlin
// 金额的三种写法，按顺序尝试
private val amt1 = Regex("""[¥￥]\s*([0-9][0-9,]*(?:\.[0-9]{1,2})?)""")   // ¥25.00
private val amt2 = Regex("""([0-9][0-9,]*(?:\.[0-9]{1,2})?)\s*元""")       // 25.00元
private val amt3 = Regex("""人民币\s*([0-9][0-9,]*(?:\.[0-9]{1,2})?)""")    // 人民币25.00

// 商户：从"向/在/给 XXX 支付"里抠
private val mer1 = Regex("""(?:向|在|给)\s*([\u4e00-\u9fa5A-Za-z0-9·\-]{2,18}?)(?:支付|付款|消费|转账|充值|购买|下单|扫码)""")
```

### 典型问题：某银行短信格式抓不到

假设你的银行短信是：

```
【建设银行】您账户5678于11月06日支付25.00元，商户：星巴克
```

- 金额：`25.00元` → `amt2` 能匹配 ✅
- 商户：`商户：星巴克` → `mer2`（`商户[：:]\s*(...)`）能匹配 ✅
- 所以理论上能记上。若不能，把原文发我。

### 典型问题：通知里金额写成「25」没有小数点

`amt2` 的 `([0-9][0-9,]*(?:\.[0-9]{1,2})?)\s*元` 也能匹配整数「25元」✅

### 典型问题：抓错了数字（比如抓到了卡号尾号）

加一条**更具体**的正则放在最前面即可，比如：

```kotlin
private val amt0 = Regex("""支付金额[:：]?\s*[¥￥]?([0-9][0-9,]*(?:\.[0-9]{1,2})?)""")
```

然后把它加进 `pickAmount` 里的列表第一个：

```kotlin
for (re in listOf(amt0, amt1, amt2, amt3)) {
```

### 调整"什么算支付"

```kotlin
private val expenseWords = listOf("支付", "付款", "消费", "扣款", "支出", "缴费", "扣费", "交易")
private val incomeWords = listOf("收款", "入账", "转入", "退款", "到账", "收到", "收入", "存入")
private val negativeWords = listOf("待支付", "待付款", "请尽快", "即将", "将于", "优惠", ...)
```

- 出现 `negativeWords` 且没有「成功」→ 直接丢弃（防误记"待支付"）
- 出现「退款/收款/入账/转入/存入」→ 记为收入

## 改完怎么验证

不需要装 Android Studio：

1. 打开手机上的蜜蜂记账 →「我的」→「捕获日志」，找到没识别的那条，**长按复制**原始文本
2. 在电脑上用任意文本编辑器（记事本就行）修改对应的 `.kt` 文件
3. GitHub 网页上找到该文件 → 铅笔图标编辑 → 粘贴 → Commit
4. Actions 自动重新编译 → 下载新 APK → 覆盖安装（数据不丢）
5. 再付一笔同样的钱，看日志

## 分类名称对照表

改词库时「分类名」必须从这里选（区分收支）：

**支出**：餐饮、交通、购物、日用、娱乐、居住、医疗、教育、通讯、人情、宠物、旅行、美容、数码、运动、服饰、其他

**收入**：工资、奖金、红包、退款、理财、兼职、其他收入

想新增分类（比如「房贷」「赡养」），需要改三个地方：

1. `Cats.kt` 里加一行 `Cat("房贷", "🏦", 0xFF795548, Type.EXPENSE)`
2. `AutoCat.kt` 里加关键词指向它
3. 重新编译

图标用 emoji 就行，不用找图片资源。
