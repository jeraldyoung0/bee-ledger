# 03 · 手机授权与日常使用

装好 App 只是第一步。**没有下面的授权，自动记账等于没装。**

本 App 有四个"抓取通道"，按重要性排序：

| 通道 | 需要什么权限 | 抓什么 |
|---|---|---|
| ① 读屏识别 | 无障碍 | 微信/支付宝/抖音/拼多多/云闪付 的「支付成功」页 |
| ② 通知监听 | 通知使用权 | 微信收款、云闪付、银行 App 的动账通知 |
| ③ 短信 | 短信权限 | 银行卡消费短信 |
| ④ 账单导入 | 无 | 手动补历史 |

---

## 一、最重要：开启「读屏记账」（无障碍权限）

### 为什么必须要它

微信、支付宝、抖音、拼多多在**付款**时，你正看着它们的支付页面（前台），
安卓**不会弹出通知**，所以通知监听永远抓不到付款。

唯一能看到金额的地方，就是那个「支付成功」页面本身。读屏就是干这个的。

**这不是偷看你的聊天**：系统层面只放行 5 个 App 的界面事件
（`com.tencent.mm`、`com.eg.android.AlipayGphone`、`com.ss.android.ugc.aweme`、
`com.xunmeng.pinduoduo`、`com.unionpay`），其他应用的界面**根本不会送到本服务**。

### 开启步骤（HyperOS 3）

1. App 内 →「我的」→「读屏自动记账」→ **去开启**
2. 系统跳到「无障碍」列表，找到 **蜜蜂记账 · 读屏记账**
3. 点进去 → 打开开关 → 弹窗点「允许」

如果列表里找不到：
> 设置 → 更多设置 → 无障碍 → 已下载的应用

### Android 13+ 的坑：受限制的设置

如果你的手机是 Android 13 及以上（HyperOS 3 都是），从网页/apk 安装的应用会被标记为
「未知来源」，**无障碍开关可能直接是灰的点不动**，提示"出于安全考虑，此设置当前不可用"。

解决办法：

> 设置 → 应用设置 → 应用管理 → 蜜蜂记账 → 右上角 **⋮** → **允许受限制的设置**
> （部分版本叫"允许受限制设置"或需要先点"应用信息"里的提示卡片）

允许之后，再回去开无障碍开关就能打开了。

### 小米特有的两个坑

1. **重启后可能自动关闭**：部分 MIUI/HyperOS 版本重启会重置无障碍。
   重启后打开 App，「我的」里那行如果变回"未开启"，重新去开一次。
2. **省电策略会杀**：见第四节。

### 怎么验证生效

微信扫个码付 0.01 元 → 看到「支付成功」页面 → 回 App「明细」，
几秒内应该出现一笔，来源显示「读屏」。

没出现就去「我的 → 捕获日志」看，那里会写清楚是"没识别到金额"还是"根本没触发"。

## 二、建议开：通知使用权

「我的」→「通知使用权」→ 去开启 → 系统列表里勾选「蜜蜂记账」。

- 抓的是**收款**类通知（微信收款到账、云闪付、银行 App 动账）
- 各品牌路径：

| 品牌 | 路径 |
|---|---|
| 小米 / 红米 | 设置 → 应用设置 → 特殊权限 → 通知使用权 |
| 华为 / 荣耀 | 设置 → 应用和服务 → 应用管理 → 蜜蜂记账 → 通知使用权 |
| OPPO / 一加 | 设置 → 通知与状态栏 → 通知使用权 |
| vivo | 设置 → 通知与状态栏 → 通知使用权 |
| 三星 | 设置 → 通知 → 高级设置 → 通知使用权 |
| 原生 / Pixel | 设置 → 应用 → 特殊应用权限 → 通知使用权 |

---

## 三、建议开：短信权限

「我的」→「短信读取权限」→ 去授权 → 允许「接收短信」「读取短信」。

银行短信是最后一道网：读屏没覆盖的场景（比如在浏览器里付款、线下刷卡短信），
靠它兜底。注意**部分银行 500 元以下不发短信**，这类只能靠读屏或手动。

---

## 四、HyperOS 3 后台保活（必做）

安卓厂商会杀后台，服务被杀就抓不到。**这不是 App 的 bug，是系统省电策略。**

1. **自启动**：手机管家 → 应用管理 → 蜜蜂记账 → 自启动 ✅
2. **省电策略**：设置 → 应用设置 → 应用管理 → 蜜蜂记账 → 省电策略 → **无限制**
3. **后台运行**：同上页面 → 后台运行 → 允许
4. **锁定后台**：多任务界面，把蜜蜂记账卡片**下拉**（出现 🔒）

## 五、第一次使用的自测清单

| # | 操作 | 预期结果 |
|---|---|---|
| 1 | 微信扫码付 0.01 元 | 明细出现，来源「读屏」 |
| 2 | 支付宝付 1 元 | 明细出现，来源「读屏」 |
| 3 | 微信收款 0.01 元 | 明细出现，来源「通知」 |
| 4 | 拼多多下一单（选银行卡） | 明细出现，来源「读屏」——**不需要银行短信** |
| 5 | 银行卡直接刷卡消费 | 明细出现，来源「短信」 |
| 6 | 同一笔记两次 | 应被去重（同金额 2 分钟内只记一次） |
| 7 | 把自动记的分类改掉 | 生成规则，下次同商户自动分对 |
| 8 | 我的 → 导出账单 | CSV 能用 Excel 打开不乱码 |

## 六、日常使用要点

- **每天扫一眼**：自动记的账带「自动」标，分类可能不准，点一下改，改一次学一次。
- **月底对账**：支付宝/微信导出账单，App 里「导入账单」补齐漏记（已存在的不会重复导）。
- **预算**：「我的 → 月度预算」，首页显示进度条。
- **删除**：点开账目 → 右上角「删除」。

## 七、故障排查表

| 症状 | 可能原因 | 处理 |
|---|---|---|
| 付款完全不记账，日志也空 | 无障碍没开 / 被系统关了 | 检查「我的」里那行是否"已开启" |
| 付款记账了，但两次 | 读屏 + 短信各触发一次 | 手动删一条；若频繁，关掉短信通道 |
| 聊天页面被误记 | 页面里恰好有"支付成功"和金额 | 日志里能查到，删掉即可；把那条原文发我收紧规则 |
| 打开历史账单被误记 | 查账单页面含"支付成功" | 已加过滤（交易单号/账单详情等），仍有漏网发我 |
| 收款能记、付款不能 | 无障碍没开或被杀 | 见第一节 |
| 金额抓错 | 页面里有多个数字 | 把日志原文发我调正则 |
| 分类不准 | 词库没覆盖 | 改一次分类即学习；或手动加规则 |
| 重启后失效 | 小米重置无障碍 | 重新开一次无障碍 |
| 导入 CSV 解析不到 | 导出的是 zip 不是 csv | 解压出 .csv 再导入 |
| 换手机数据没了 | 数据只在本机 | 先导出 CSV，新机导入 |
