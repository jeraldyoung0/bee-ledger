# 03 · 手机授权与日常使用

装好 App 只是第一步。**没有下面的授权，自动记账等于没装。**

---

## 一、必须做：开启「通知使用权」

这是自动记账的核心。安卓规定这个权限**只能用户手动开**，任何 App 都无法弹窗申请。

### 通用路径

App 内「我的」→ 点「通知使用权」右边的「去开启」→ 系统会跳到「设备与应用 → 通知使用权 / 通知访问权限」列表 → 找到 **蜜蜂记账** → 打开开关 → 弹窗点「允许」。

### 各品牌大致路径（系统版本不同会略有差异）

| 品牌 | 路径 |
|---|---|
| 小米 / 红米 (HyperOS/MIUI) | 设置 → 应用设置 → 应用管理 → 蜜蜂记账 → 通知使用权 → 允许 |
| 华为 / 荣耀 (HarmonyOS/EMUI) | 设置 → 应用和服务 → 应用管理 → 蜜蜂记账 → 通知使用权 |
| OPPO / 一加 (ColorOS) | 设置 → 通知与状态栏 → 通知使用权 → 蜜蜂记账 |
| vivo (OriginOS) | 设置 → 通知与状态栏 → 通知使用权 |
| 三星 (One UI) | 设置 → 通知 → 高级设置 → 通知使用权 |
| 原生 / Pixel | 设置 → 应用 → 特殊应用权限 → 通知使用权 |
| 魅族 (Flyme) | 设置 → 通知和状态栏 → 通知使用权 |

开完后回到 App，那一行应该变成绿色的「已开启」。没变的话，切一下底部标签页再回来。

### 验证是否生效

1. 打开微信，给任意好友转账 0.01 元（或者支付宝买一瓶水）。
2. 回到蜜蜂记账「明细」，几秒内应出现一笔，带一个蓝色「自动」小标。
3. 如果没出现，去「我的 → 捕获日志」看：如果日志里连原始文本都没有，说明通知使用权没生效；如果有文本但标「未识别」，说明文案没匹配上，需要调解析规则。

---

## 二、建议做：短信权限

「我的」→「短信读取权限」→「去授权」→ 允许「接收短信」和「读取短信」。

- 不开也能用，只是银行卡直接消费会漏记。
- 部分手机会把这两个权限收进「特殊权限」，按提示走即可。
- 若系统提示"此应用不是默认短信应用"，忽略即可——我们只读不发。

---

## 三、强烈建议做：后台保活

安卓厂商会杀后台，服务被杀就抓不到通知。**这不是 App 的 bug，是系统省电策略。**

### 通用三件事

1. **允许自启动 / 允许后台活动**
   - 小米：设置 → 应用设置 → 蜜蜂记账 → 自启动、后台弹出界面、省电策略选「无限制」
   - 华为：设置 → 应用 → 蜜蜂记账 → 耗电详情 → 允许后台活动
   - OPPO/一加：设置 → 电池 → 应用耗电管理 → 蜜蜂记账 → 允许后台运行
   - vivo：设置 → 电池 → 后台耗电管理 → 允许后台高耗电
2. **加入电池优化白名单**
   设置 → 电池 → 电池优化 → 找到蜜蜂记账 → 选「不优化」
3. **最近任务里锁定**
   多任务界面下拉 App 卡片（出现小锁），防止一键清理时被杀

### 通知权限也要给

App 自己不需要发通知，但如果系统层面禁用了它的通知通道，某些 ROM 会连带影响监听服务的存活。**保持通知开启是安全的。**

## 四、第一次使用的自测清单

按顺序做一遍，全部通过就说明配置正确：

| # | 操作 | 预期结果 |
|---|---|---|
| 1 | 微信转账 0.01 元 | 明细出现 0.01，分类「其他」或「人情」 |
| 2 | 支付宝买 1 元商品 | 明细出现，来源「通知」 |
| 3 | 用银行卡快捷支付一笔 | 明细出现，来源「短信」 |
| 4 | 同一笔重复付款 2 次同金额 | 都记上（超过 3 分钟的不会误判重复） |
| 5 | 手动记一笔 12.5 元 | 正常保存 |
| 6 | 点开自动记的那笔，把分类改成「餐饮」 | 保存后产生一条规则，下次同商户自动分「餐饮」 |
| 7 | 我的 → 导出账单 | 生成 CSV，Excel 能打开不乱码 |

## 五、日常使用要点

- **每天扫一眼**：自动记的账带「自动」标，分类可能不准，点一下就能改，改一次学一次。
- **月底对账**：用支付宝/微信导出账单，App 里「导入账单」补齐漏记的（已存在的不会重复导）。
- **预算**：「我的 → 月度预算」设一个数，首页会显示进度条，超了变成满格。
- **删除账目**：点开账目 → 右上角「删除」。

## 六、故障排查表

| 症状 | 可能原因 | 处理 |
|---|---|---|
| 完全不记账，日志也空 | 通知使用权没开 / 被杀后台 | 重开权限；按第三节保活 |
| 有日志但显示「未识别」 | 该 App 通知文案不含金额，或格式没见过 | 把日志里那行原始文本发我，我加规则 |
| 微信账单能记、支付宝不能 | 支付宝通知被系统归到"不重要通知"折叠了 | 支付宝通知设为"重要/允许横幅" |
| 同一笔记了两次 | 通知+短信各触发一次，且间隔超 3 分钟 | 属正常容错，手动删一条即可 |
| 记的金额不对 | 通知里有多个数字，抓错了一个 | 日志里看原文，发我调正则 |
| 分类总是不准 | 词库没覆盖你的商户 | 改一次分类即自动学习；或手动加规则 |
| 导入 CSV 提示解析不到 | 导出的是 zip 不是 csv，或不是支付宝/微信格式 | 解压出 .csv 再导入；确认表头有「交易时间」 |
| 换手机后数据没了 | 数据只在本机 | 先导出 CSV，新手机导入 |
| 手机重启后不记账 | 自启动被禁 | 开启自启动权限 |
